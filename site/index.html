Share the picture, not where you took it.

A command-line tool that removes metadata from photos and videos: location, camera and owner details, dates, editing software, keywords. It keeps the orientation and color profile, so files look exactly the same.

Clean files that still look right

exiftool can already delete tags. clean-assets-meta knows which ones to keep, handles the formats that need special care, and makes the safe choice the default.

Strip

Removes GPS, camera serial numbers, owner names, dates, software and keywords from images and videos, in place or as copies with --out.

Keeps the look

The orientation and color profile stay, so a portrait photo isn't turned sideways and a Display P3 image keeps its colors. --all removes them too.

Dry run

-n lists each file with how many metadata tags it has and whether it carries a location, before anything changes.

Videos too

MP4 and MOV metadata is removed, and the creation dates their headers can't drop are set to zero. The rotation stays.

Apply it back

apply copies metadata from an original onto edited or stripped copies, one file or whole folders matched by path.

Presets

Save the options you use with --save-preset web, reuse them with -p web, and share a project's presets in a .clean-assets-meta.json.

What goes, what stays

By default. --gps-only removes the location and nothing else; -k Copyright keeps a tag you want.

Removed

  • Location: GPS coordinates, altitude, place names
  • Camera and lens make, model and serial numbers
  • Owner, artist, copyright and creator
  • Capture and edit dates (zeroed in video headers)
  • Editing software and history, keywords, descriptions
  • macOS extended attributes: download source, quarantine, Finder tags

Kept

  • Orientation, so photos stay upright
  • Color profile, so colors don't shift
  • A video's rotation and color information
  • The pixels: images aren't re-encoded

Install in a minute

Requires Node.js 24 or later and exiftool. Developed and tested on macOS.

1. Install

brew install exiftool
npm install -g clean-assets-meta

Or try it first with npx clean-assets-meta strip photo.jpg -n.

2. Clean

clean-assets-meta strip photo.jpg
clean-assets-meta strip ./exports -r -o ./clean
clean-assets-meta strip --help

See the README for every option.
